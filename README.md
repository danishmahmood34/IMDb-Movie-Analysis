# 🎬 IMDb Movie Analysis — Python

## 📌 Project Overview

Exploratory analysis of 1,000 IMDb movies using Python to identify trends in ratings, revenue, genres, directors, runtime, and audience votes.

## 🛠️ Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Key Analysis

- Top-rated and highest-revenue movies
- Movie trends by year
- Genre popularity and ratings
- Director performance
- Rating vs. revenue relationship
- Runtime and audience-vote analysis

## 📊 Visualizations

The notebook includes charts using **Matplotlib and Seaborn** to explore movie ratings, revenue, yearly trends, and other relationships.

## 📁 Files

- `imdb_data.csv` — Source dataset
- `IMDB_Movie_Analysis.ipynb` — Python analysis notebook
